# Examples

- [Persistent workstream](persistent-workstream/) — multiple adjacent Builder tasks followed by a forced Reviewer rotation
- [Software feature](software-project/) — classic always-fresh streaming parser task
- [ML experiment](ml-experiment/) — bounded experiment design and job handoff
- [Data pipeline](data-pipeline/) — schema migration task
- [Research repository](research-repo/) — preregistration, execution, and scientific review separation

Examples are illustrative and intentionally small. The persistent-workstream example is the recommended RSAW 0.2 starting point; the others also demonstrate backward-compatible RSAW 0.1 patterns.
