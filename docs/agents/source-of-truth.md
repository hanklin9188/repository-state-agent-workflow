# Source of Truth

| Information | Canonical source |
|---|---|
| Stable agent rules | `AGENTS.md` |
| Current continuation state | `ACTIVE.md` |
| Active work contract | `docs/tasks/<task>.md` |
| Load-bearing decisions | `docs/decisions/` |
| Implementation truth | Code + tests |
| Broad project status | Project-defined status document |
| Measured evidence | Immutable artifacts and hashes |
| Historical continuity | Git history and archived handoffs |

`ACTIVE.md` points to authority. It does not replace authority.
