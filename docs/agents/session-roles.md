# Session Roles

## Builder

Read policy, active state, task, and exact code dependencies. Implement, validate, update handoff, stop.

## Reviewer

Start fresh. Read the task, diff, tests, and review questions. Do not preload debugging history.

## Decision

Under Medium reasoning, use two passes:

1. evidence decomposition;
2. decision synthesis.

Record a compact decision checkpoint between passes when the problem is large.
