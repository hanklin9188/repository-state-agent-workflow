# Repository-State Workflow

1. Start a fresh session.
2. Read `AGENTS.md`, `ACTIVE.md`, and the active task.
3. Expand context only when required.
4. Complete one bounded task.
5. Use V0/V1 during iteration.
6. Use V2 at stable closure.
7. Use a fresh reviewer for V3-critical work.
8. Update `ACTIVE.md` with pointers, next action, and stop condition.
9. Stop.

For long-running work, record the job and stop instead of busy-waiting.

For scientific or major architecture decisions under Medium reasoning, split evidence decomposition and synthesis into separate passes or sessions.
