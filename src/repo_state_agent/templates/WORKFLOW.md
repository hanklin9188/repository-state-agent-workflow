# Repository-State Workflow

1. Read `AGENTS.md`, `ACTIVE.md`, and the active task.
2. Expand context only when the active task requires it.
3. Execute one bounded task.
4. Use V0/V1 while iterating and V2 at closure.
5. Update `ACTIVE.md` with pointers, next action, and stop condition.
6. Stop and use a fresh session for the next task or role.

Use a fresh reviewer for critical work. Use a two-pass Medium decision workflow for major architecture or scientific forks.
