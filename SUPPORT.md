# Support

## Questions and adoption help

Use GitHub Issues with the `workflow feedback` or `adoption case study` template. Include a minimal repository layout and redact proprietary information.

## Bugs

Use the bug report template and include:

- `rsaw --help` / installed version;
- Python version;
- operating system;
- exact command;
- minimal `AGENTS.md`, `ACTIVE.md`, and task structure;
- expected and actual result.

## Security

Do not disclose security issues or secrets in a public issue. Use GitHub's private security advisory mechanism. See [SECURITY.md](SECURITY.md).

## Scope

The project supports its templates and deterministic CLI. It cannot provide support for every coding-agent vendor, model provider, CI platform, or company-specific governance system.
